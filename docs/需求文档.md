# 广西壮文化 MR 交互游戏功能需求文档

项目类型：MR虚实融合非遗交互体验（壮族纹样 + 民乐打击）
运行设备：6DoF MR头显 + 6DoF 单/双交互手柄

## 需求概括

### 第一章

**开始游戏界面**：玩家点击开始游戏加载后即可进入关卡选择 P2，玩家可通过操控手柄摇杆向左划，移动关卡图标，点击图标后进入第二章，按下图标后图标旋转一周进入。

### 第二章

要玩家操控手柄在场景里面行走，每走到壮族纹样的地方会出现提示，玩家可以点击纹样，点击后弹出 P2 绘制窗口，玩家根据提示后绘制完成自动关闭窗口，玩家继续往前，完成三个纹样绘制后进入音乐打击关卡。

### 第三章

玩家在进入关卡的时候需要进入倒计时，进去关卡后根据音乐节奏打击，打击图为 P2，玩家通过点击中心的圆环，环外点击 miss，外环线点击为良好，环内点击为完美，内环线点击为 good，环内为 miss。单击即点击一侧，在环内点击对应的符号会响应对应的实色部分圆弧，双击为点击双侧，长按需要玩家操作按钮长按。中间音符打击穿插之前的纹样绘制，玩家跟着纹样绘制图案即可继续完成音符打击，完成三次纹样绘制和打击全部音符后即可通关，反之则失败需要重新再来。通关结束后显示地主被火燃烧的动画，玩家不用操作等待 4s 即可。动画结束后出现卡面介绍，玩家可点击两侧箭头实现更换卡片页面，卡片内容为游戏纹样的详细介绍。

## 详细需求

## 第一章

### P1：开始游戏界面（第一张图）MR需求
### P2：关卡选择界面（第二张图）MR需求

#### 一、整体基础 MR 通用需求

1. **虚实融合显示**
   - 实景摄像头画面作为底层背景（办公室真实环境实时透视），上层叠加 2D 卡通国风壮族元素 UI 图层，图层带半透紫色国风边框，前景、背景元素分层渲染，不遮挡手部 VR 手柄。
   - 支持手柄实时透视识别，手部持有的 VR 控制器在画面中正常显示，UI 元素可与手柄做空间交互判定。

2. **手柄交互底层逻辑**
   - 识别 VR 手柄摇杆左右滑动、按键点击两类输入；
   - 所有 UI 交互具备物理反馈：选中高亮、旋转动画、位置位移缓动；
   - 空间碰撞检测：手柄射线可远距离选中悬浮虚拟 UI 图案。

3. **资源美术规范**
   - 视觉风格：粉紫渐变山水、祥云、壮族绣球、壮锦铜鼓纹样、塔楼风雨桥扁平化卡通；
   - 悬浮 UI 元素带描边、渐变填充，悬浮在空中不贴合实景平面。

#### 二、P1：开始游戏界面（第一张图）MR需求

**1. 界面视觉层需求**
1. 底层：实时摄像头实景（办公室桌面、电脑、手办展柜）。
2. 中层背景装饰（静态悬浮国风元素）
   - 左右对称壮锦菱形边角纹样；
   - 粉紫色层叠远山、祥云漂浮图层；
   - 左侧古塔、中间风雨桥、右侧飞鸟剪影；
   - 全界面外围紫色粗边框。
3. 中心核心交互物体：巨型壮族绣球悬浮于画面正中央，绣球自带三色渐变流苏，采用绿紫黄壮锦几何纹样。
4. 绣球底部文字：悬浮文字「进入游戏」，半透绿色字体。

**2. 交互流程需求**
1. 玩家手持 VR 手柄，手柄发射交互射线；
2. 射线命中中心绣球/「进入游戏」文字时，绣球轻微放大高亮；
3. 按下手柄确认键触发加载动画：
   - 绣球缓慢缩放淡出，所有国风装饰元素逐层消散；
   - 增加过渡加载淡入淡出转场特效；
4. 加载完成后自动跳转至 **P2 关卡选择界面**。

#### 三、P2：关卡选择界面（第二张图）MR需求

**1. 界面视觉层需求**
1. 底层：同实时实景摄像头透视画面；
2. 界面边框：上下紫色斜切装饰边框，取消左右壮锦边角纹样；
3. 交互元素：左右悬浮 2 张对称**壮锦凤凰纹样关卡图标**，卡片式悬浮 UI，带橙色底 + 紫色凤凰非遗图案。

**2. 摇杆滑动交互逻辑**
1. 手柄左摇杆**向左滑动**：
   - 触发所有关卡图标整体向画面左侧平移缓动；
   - 可循环滚动关卡卡片（预留拓展多关卡能力）；
   - 滑动过程中卡片保持悬浮空间感，带轻微位移拖尾动画。
2. 摇杆向右滑动：图标向右平移复位。

**3. 点击选中进入关卡逻辑**
1. 手柄射线对准任意凤凰关卡图标，图标边缘高亮提示可点击；
2. 按下手柄确认键：
   - 当前选中关卡图标原地匀速旋转完整一周（360° 旋转动画）；
   - 旋转完成后触发场景切换，加载对应第二章游戏关卡；
3. 容错机制：射线未命中图标时，点击无任何动画、无场景跳转。

#### 四、动画与特效统一需求

1. UI 动效：位移、缩放、旋转均使用缓动曲线，避免生硬瞬移；
2. 转场：界面切换采用淡入淡出溶解过渡；
3. 选中反馈：所有可交互物体命中后放大 10% + 色彩提亮；
4. 虚实遮挡：手柄手部实景永远渲染在 UI 图层最上层，不被虚拟图案遮挡。

#### 五、拓展适配需求

1. MR 透视适配：支持室内实景动态光线变化，UI 亮度自动适配环境；
2. 多关卡拓展：摇杆滑动逻辑支持新增 3/4/更多关卡卡片横向排列滑动；
3. 性能需求：2D 卡通 UI 轻量化渲染，不占用 MR 透视相机算力，保证画面流畅无掉帧。

## 第二章节

项目类型：MR 虚实融合非遗交互体验（壮族纹样 + 民乐打击）
运行设备：6DoF MR 头显 + 6DoF 单/双交互手柄
核心流程：空间漫游寻纹样 → 手绘临摹纹样 → 三关完成解锁民乐打击关卡
美术基准：参考截图紫色壮锦边框、剪纸虚拟纹样、铜鼓几何纹样绘制界面

### 一、程序功能需求（前端/交互逻辑）

**1. 空间漫游系统**

1.1 定位追踪
- 头显 6DoF 空间定位，实时透视真实环境作为底层画面，无需虚拟地板，直接依托现实室内场景行走
- 支持两种移动模式，可切换：
  ① 物理行走：玩家身体真实前后左右移动，虚拟视野同步跟随；
  ② 手柄摇杆移动：摇杆推动实现平滑位移，头部控制视角朝向

1.2 碰撞与空间判定
- 3 处壮族虚拟纹样挂载球形碰撞盒，触发距离 1.2 米；玩家进入范围激活交互提示，离开范围提示消失
- 弹窗开启时，屏蔽场景漫游移动，仅保留手柄射线操作；弹窗关闭后恢复行走功能

1.3 手柄基础交互
- 手柄发射可视化射线，用于选中虚拟纹样、画布手绘、UI 按钮操作
- 扳机键：确认点击、手绘落笔持续绘制；侧键：手动关闭绘制弹窗

**2. 纹样触发交互逻辑**

2.1 纹样状态切换
- 默认状态：半透明剪纸/铜鼓纹样，低亮度；
- 可交互状态（玩家靠近）：纹样外发光特效 + 循环淡入淡出动画，同步播放短促壮族装饰音效
- 射线悬停纹样：射线光标变色，纹样高亮强化

2.2 点击弹窗逻辑
- 射线对准纹样按下扳机，立即弹出全屏半透明绘制 UI 窗口，层级置顶覆盖实景 + 场景虚拟物件
- 弹窗弹出瞬间添加淡入动画，背景实景降低透明度，突出绘制画布

**3. 纹样绘制窗口核心逻辑**

3.1 画布绘制功能
- 窗口中间放置标准壮族纹样底图（铜鼓同心圆回纹、壮锦菱形纹、花卉剪纸纹各一套）
- 手柄扳机按住拖动射线，在画布内自由绘制线条，支持线条粗细、颜色统一（金色线条临摹）
- 支持撤回、清空画布快捷按钮

3.2 绘制完成判定
- AI 轮廓匹配识别：玩家手绘线条与标准纹样重合度 ≥ 80% 判定绘制完成
- 完成触发逻辑：
  1）播放完成特效 + 成功提示音；
  2）全局完成计数 +1（界面角落实时显示进度：1/3、2/3、3/3）；
  3）弹窗自动淡出关闭，返回漫游场景，该纹样标记为已完成，不再重复弹窗

3.3 异常处理
- 玩家未完成可按手柄侧键手动关闭弹窗，纹样保留可重复点击绘制，不计入完成进度

**4. 进度与关卡跳转系统**

4.1 进度存储
- 本地缓存已完成纹样数量，重启体验不重置进度

4.2 关卡切换触发
- 当完成计数 = 3 时，触发全局过场动画：全屏铺展壮族纹样粒子特效，背景音乐切换为民乐前奏
- 动画结束后自动加载音乐打击关卡，关闭漫游场景，切换打击交互逻辑

4.3 音乐打击关卡交互
- 手柄作为打击道具，空中悬浮壮族铜鼓、绣球音符判定区域
- 音符随壮族民歌节拍匀速下落，手柄触碰/扳机击打音符判定得分，匹配节拍播放对应乐器音效

**5. 全局 UI 框架程序逻辑**
- 画面四周固定壮锦边框 UI，全程置顶，不随场景、弹窗隐藏
- 界面角落常驻进度文字：已绘制纹样/总纹样（0/3 ~ 3/3）

过场动画：完成计数 = 3 时触发（详见 4.2）。

## 第三章节

前置流程：玩家完成 3 处漫游场景纹样绘制 → 自动转场进入本音乐打击关卡
交互硬件：6DoF MR 头显 + 6DoF 单手柄（射线/按键/长按/双击识别）

### 一、关卡前置：进入倒计时模块需求

**1. 视觉表现（对应第一张图：数字 3 倒计时）**
1. 全屏居中大号白色倒计时数字「3 → 2 → 1」，数字外层套双层金色铜鼓圆环；
2. 圆环底层是壮族反派（地主恶霸）剪纸剪影，左右搭配紫色破碎壮锦装饰；
3. 左上角常驻六边形「设置」悬浮按钮，全程不消失。

**2. 程序逻辑**
1. 倒计时时长 3 秒，每秒数字切换一次，同步对应鼓点音效；
2. 倒计时结束无缝切入音乐打击主界面，无黑屏断层；
3. 倒计时阶段锁定行走漫游，仅保留左上角设置按钮可交互。

### 二、核心：音乐节奏打击交互系统（第二张打击判定界面）

**1. 判定圆环分层规则（从外至内分层，严格计分判定）**

界面核心：同心双层金色打击圆环，上方横向节拍进度条。

| --- | --- |
| 环外 | Miss |
| 外环线 | 良好 |
| 环内 | 完美 |
| 内环线 | Good |
| 环内（另一情形） | Miss |

**2. 手柄多操作识别逻辑（单击/双击/长按）**
1. 单击扳机键：仅点亮当前点击方位单侧圆弧色块，匹配单音节节拍；
2. 双击扳机键（短时间内连续点击 2 次）：同步点亮左右双侧圆弧色块，适配双音节重拍；
3. 长按扳机键：持续填充对应方位圆弧，适配长音拖拍音符，松开即停止填充；
4. 判定容错：音符到达圆环判定区 ±0.3s 内点击有效，超出窗口直接判定 Miss。

**4. 游戏关卡音效**
- 通关失败界面为破碎声
- 通关成功界面为鼓声
- 通关后地主动画，其中火焰音量需从小到大

**5. 生命值 & 失败机制**
- 连续 3 次 Miss 直接触发**失败弹窗**（紫色壮族花纹底 + 白色「失败」大字）；
- 失败弹窗停留 2 秒，自动重置本关卡，回到倒计时界面重新挑战；
- 失败期间暂停背景音乐，播放低沉警示音效。

### 三、穿插机制：打击中途插入纹样绘制弹窗

**1. 触发规则**

音乐节拍行进中，固定 3 次强制打断打击流程，弹出纹样临摹绘制窗口（第三张铜鼓纹样绘制界面），逻辑复用前期漫游绘制模块：
1. 弹窗弹出时冻结音符下落、暂停背景音乐；
2. 窗口为紫色壮锦回纹边框，中间展示标准壮族铜鼓同心圆纹样；
3. 玩家使用手柄射线临摹绘制，线条匹配度 ≥ 80% 判定绘制完成；

**2. 完成/未完成分支**
1. 绘制达标：弹窗自动关闭，恢复音乐打击、音符继续下落，解锁下一段节拍；
2. 超时/匹配度不足：直接判定全局关卡失败，弹出失败界面，从头重开；
3. 全局计数：必须完整通过 **3 次纹样绘制打断** + 全部音符节拍完美/良好判定，才算通关。

### 四、通关判定

**1. 通关触发条件**

同时满足两项条件：
① 3 次穿插纹样绘制全部完成；
② 所有下落音符均达成 Good/完美/良好判定，无累计超量 Miss（10 个 Miss 为超量）

**2. 胜利反馈弹窗**

达成通关瞬间弹出金色壮锦花纹底 + 白色「胜利」大字全屏特效，播放欢快壮族民乐高潮音效。

### 过场动画模块

**反派结局动画（火焰燃烧地主纹样）**
1. 胜利弹窗结束后自动切换全屏动画：紫色背景，地主恶霸剪纸剪影，底部持续燃烧橙红色火焰，火焰逐步向上吞噬剪影；
2. 动画强制时长 4 秒，全程锁定玩家操作，手柄、头显无任何交互权限，仅观看；
3. 动画无跳过按钮，倒计时结束自动跳转纹样介绍卡面界面。

### 五、收尾：纹样图鉴卡片浏览系统（最后一张卡面界面）

**1. 界面视觉布局**
1. 半透明紫色异形壮锦边框全屏弹窗；
2. 左侧白色左箭头、右侧白色右箭头切换按钮；
3. 左侧展示对应纹样黑白剪纸剪影，右侧为标题 + 文字科普介绍；
4. 左上角「设置」按钮全程保留。

**2. 交互逻辑**
1. 手柄射线点击左/右箭头，切换不同壮族纹样科普卡片（包含铜鼓纹、花卉纹、地主恶霸叙事纹等全部游戏内纹样）；
2. 卡片可无限循环前后翻阅，无操作时长限制；
3. 支持点击左上角设置按钮返回关卡重玩/回到前期漫游场景。

### 六、美术资源细分需求

1. **打击关卡 UI**：同心双层金色判定圆环、顶部节拍进度条、左右破碎紫色壮锦装饰；胜利：金色八角壮锦底纹；失败：深紫色八角壮锦底纹；
2. **倒计时资产**：3/2/1 大号书法数字、地主剪纸底层剪影、粒子淡入淡出动画；
3. **绘制复用资产**：紫色回纹边框绘制窗口、铜鼓标准临摹纹样、手绘金色线条图层；
4. **结局动画资产**：紫色纯色背景、恶霸静态剪纸、循环燃烧火焰逐帧动画；
5. **图鉴卡片资产**：异形壮锦弹窗边框、左右翻页箭头、全纹样剪影素材、国风科普文字字体。

### 七、音频完整需求

1. 倒计时：每秒单声轻铜鼓；
2. 打击背景音乐：壮族改编民乐（铜鼓、芦笙、山歌伴奏），分段落，绘制弹窗时音量减弱暂停；
3. 分段打击音效：完美（重鼓）、良好（轻鼓）、Good（敲锣）、Miss（刺耳破音）、长按持续拖音；
4. 绘制成功：毛笔收尾沙沙声；绘制失败：短促警示音；
5. 胜利界面：民乐高潮合奏；失败界面：低沉闷鼓；
6. 火焰结局动画：柴火燃烧音效 + 渐弱民乐尾声；
7. 图鉴翻页：壮锦布料滑动轻响。

### 八、全关卡完整流程时序

进入音乐关卡 → 3 秒数字倒计时动画 → 音乐打击界面启动，音符沿进度条下落 → 节拍中途 3 次强制弹出纹样绘制窗口，完成后恢复打击 → 全部音符 + 3 次绘制均达标 → 弹出胜利特效 → 自动播放 4 秒火焰燃烧反派动画（不可操作） → 动画结束跳转纹样科普图鉴卡面 → 玩家可自由翻页浏览全部纹样介绍，或返回重玩关卡 → 若任意绘制失败/音符大量 Miss → 弹出失败界面，重置回到倒计时重新挑战

### 九、程序验收标准

1. 倒计时数字切换流畅，3 秒后正常切入打击界面；
2. 圆环四层区域判定精准，单击/双击/长按三种操作识别无延迟、无错判；
3. 绘制弹窗 3 次正常穿插，冻结音符、暂停音乐逻辑生效；
4. 通关后 4 秒火焰动画强制播放，无法跳过；
5. 图鉴左右箭头翻页流畅，全部纹样卡片加载正常；
6. 失败条件触发后可正常重置关卡，流程闭环无卡死。
