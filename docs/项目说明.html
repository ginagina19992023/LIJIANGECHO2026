漓江回声

壮族纹样临摹与民乐节奏打击的虚实融合游戏。本页说明整体设计思路、Unity 工程打开方式，以及在 Meta Quest 3 上跑通 MR 的完整流程。

Unity 2022.3.62f3 LTS OpenXR / Passthrough Meta Quest 3
◇ ◇ ◇

01设计思路

三层分离——美术、逻辑、MR 各管各的，互不耦合，可以并行推进：换美术不用改代码，调节奏不用碰交互。

美术层 / Art分层场景 · png · mp4只管“长什么样”。你的 start-screen / level-selection / level / cutscene 等分层美术。
逻辑层 / LogicC# 脚本 · 状态机 · 判定 · 谱面只管“怎么玩”。挂在美术物体上，靠事件被调用。
MR 层 / RealityOpenXR 透视 + 手柄射线只管“虚实融合与输入”。全局底座，切场景不动它。

一条状态机串起全程

GameFlowManager 用 GameState 枚举控制当前在哪个界面，每个界面脚本订阅 OnStateChanged 自动显隐。整条流程就是下面这一张图——任何一处问题都能定位到是哪个状态没切对。

开始 → 选关 → 漫游 ⇄ 纹样绘制 → (三纹样完成) → 倒计时 → 打击 ⇄ 穿插绘制 → 胜利 → 火焰结局(4s) → 纹样图鉴 (任意失败 → 失败 → 回倒计时重来)

事件驱动 · 数据驱动 · 复用

  • 事件驱动：MR 里没有鼠标，手柄射线命中物体 → 触发 Hover / Select 事件 → 连到脚本方法。
  • 数据驱动：第三章全部音符（19s–1min43s）写在 NoteChart 里，改节奏只改数据。
  • 复用：纹样绘制窗口在第二章与第三章穿插处共用同一个组件。

02打开 Unity 工程

  1. 装 Unity Hub 与 Unity 2022.3.62f3 LTS；务必为该版本加装 Android Build Support（含 OpenJDK、Android SDK & NDK）——连 Quest 必须。若只装了 WebGL / Windows，在 Unity Hub 的 Installs 页点该版本的 ⚙️ → Add Modules 补上。
  2. GitHub Desktop 切到分支 claude/zhuang-culture-mr-game-lgme9n 并 Pull 到最新。
  3. Unity Hub → Open → 选 仓库根目录 D:\LIJIANGECHO2026（有 Assets 的那层）。
两个必看的坑

别开错目录：LIJIANGECHOFILEE 不是工程，只是美术文件夹。要打开的是仓库根。

美术要挪进 Assets：把 LIJIANGECHOFILE/LIJIANGECHOFILEE/ARTS（连同 .meta 一起）移动到 Assets/LijiangEcho/ARTS，否则它在 Assets 外面，Unity 看不到。

◇ ◇ ◇

03MR 与 Quest 3 连接

A · 开 MR 能力（做一次）

  • Build Settings → Android → Switch Platform。
  • XR Plug-in Management 勾 OpenXR；OpenXR 子页加 Oculus Touch Controller Profile，勾 Meta Quest Support 与 Passthrough。
  • Player Settings：IL2CPP · ARM64 · Linear。

B · 搭 MR 场景（做一次）

  • XR Origin (AR) + AR Session；相机加 AR Camera Background，背景 Alpha 设为 0 透出真实画面。
  • 两手柄加 XR Ray Interactor + 射线可视化。
  • 界面 Canvas 全设 World Space，悬浮在玩家前方 1.5–2m。

C · 连接 Quest 3 · 真机运行（推荐验证透视）

  1. 手机装 Meta Horizon app，同账号登录。
  2. app 内：设备 → Quest 3 → 开发者模式打开（需先在 Meta 官网免费注册开发者组织）。
  3. USB-C 线连头显到电脑，戴上头显点 允许 USB 调试。
  4. Unity → Build And Run，自动打包并安装到头显后启动。
  5. 戴上头显：应能看到真实房间 + 悬浮的壮族 UI。
关于透视

透视背景 只有真机上才显示，编辑器 Play 里看不到实景是正常的。想在编辑器里快速调交互与 UI 位置，用 Quest Link 串流预览（透视受限）或 XR Device Simulator 键鼠模拟。

D · 建议接入顺序

  1. A/B 配好，先 Build 一次，看到“房间 + 一个测试方块”＝ MR 底座通了。
  2. 接第一章开始界面：美术摆成 World Space Canvas，绣球加 Collider + Interactable，Hover / Select 事件连脚本。
  3. 同法接选关 → 第二章漫游绘制 → 第三章打击。每接一章 Build 验证一次。
