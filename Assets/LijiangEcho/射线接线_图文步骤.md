# 手柄射线 → 游戏脚本：接线图文步骤

本文把「射线点到物体 → 触发脚本方法」讲到每一步。先用**开始界面绣球**做完整样例，
再说**UI 按钮（图鉴箭头）**和**打击关卡（ControllerInput）**两种情况。

---

## 0. 先理清：两种点击，别混

| 你要做的 | 用什么实现 | 需要 ControllerInput 脚本吗 |
| --- | --- | --- |
| 点绣球 / 关卡图标 / 纹样（3D 物体） | Collider + **XR Simple Interactable** + 连 UnityEvent | ❌ 不用 |
| 点图鉴箭头 / 设置按钮（UI 按钮） | Button + **Tracked Device Graphic Raycaster** + Button.OnClick | ❌ 不用 |
| 打击的单击/双击/长按、摇杆移动/滑动选关 | **ControllerInput** 脚本 | ✅ 用 |

> 结论：**界面点击不用 ControllerInput**，XRI 的射线自己就能处理"悬停 + 扳机点击"。
> ControllerInput 只在"打击判定"和"读摇杆"时才用。

---

## 1. 前置条件（这些没有，下面做不了）

1. **XRI 已安装**（Package Manager 里有 `XR Interaction Toolkit`），这样才有
   "XR Simple Interactable" / "XR Ray Interactor" 组件。
2. **场景里有 XR Origin + 手柄射线**：
   - `GameObject > XR > XR Origin (VR)` 或 `(AR)`；
   - 它下面两个 Controller，各加 **XR Ray Interactor**（发射线）+ Line Renderer（看得见射线）。
   - 若用 XRI 的 **Starter Assets / XR Interaction Setup** 预制，射线已配好，直接用。

---

## 2. 完整样例：绣球（3D 物体）→ StartMenuController

### ① 让绣球能被射线"打到"

1. Hierarchy 里选中**绣球**那个物体。
2. Inspector → `Add Component` → 搜 **`Sphere Collider`**（或 Box Collider），
   调 Radius/Size 把绣球罩住（射线靠这个 Collider 命中）。
3. `Add Component` → 搜 **`XR Simple Interactable`**（XRI 提供）→ 添加。
   - 有了它，射线悬停/扳机按下时，这个物体就会发出 Hover / Select 事件。

### ② 放置 StartMenuController 脚本并填引用

1. 把 **`StartMenuController`** 挂在"开始界面根物体"上（管理整个开始界面的那个空物体，
   不是绣球本身也行）。`Add Component` → 搜 `StartMenuController`。
2. 在它的 Inspector 里把字段拖好：
   - `Root` = 开始界面根物体；
   - `Embroidery Ball` = 绣球的 Transform；
   - `Decorations` = 装饰图层的 CanvasGroup（没有可先留空）。

### ③ 把绣球的事件连到脚本方法（核心）

选中**绣球**，看它的 **XR Simple Interactable** 组件，最下面有
**`Interactable Events`** 一大块，展开：

**A. 悬停高亮**
1. 找到 **`Hover Entered`**（鼠标移上去进入）→ 点右下角 **`+`** 加一条；
2. 左下把**挂着 StartMenuController 的物体**拖进 `None (Object)` 槽；
3. 中间下拉：`StartMenuController` → `SetHover (bool)`；
4. 下面出现一个**勾选框**，**勾上**（= 传 true）。
5. 再找 **`Hover Exited`**（移开）→ `+` → 同样拖物体 → `SetHover (bool)` → **不勾**（= false）。

**B. 扳机点击进入游戏**
1. 找到 **`Select Entered`**（射线对准 + 按扳机）→ `+`；
2. 拖入挂 StartMenuController 的物体；
3. 下拉选 `StartMenuController` → **`OnConfirm ()`**（无参数那个）。

✅ 完成。现在戴上头显：射线扫到绣球 → 绣球放大高亮（SetHover）；按扳机 → OnConfirm 触发 → 淡出进选关。

## 3. UI 按钮样例：图鉴箭头 → PatternGallery

图鉴的左右箭头是 **UI（Canvas 上的 Button）**，做法略不同：

1. 图鉴 Canvas 设为 **World Space**，加组件 **`Tracked Device Graphic Raycaster`**
   （XRI 提供，让射线能点 UI）。场景里要有 **EventSystem**（含 XRI 的 UI Input Module）。
2. 左/右箭头用 **Button**（uGUI）。
3. 选中"右箭头 Button" → Inspector 最下 **`On Click ()`** → `+` →
   拖入挂 `PatternGallery` 的物体 → 选 `PatternGallery` → **`Next ()`**。
4. "左箭头 Button" 同理，选 **`Prev ()`**。
5. 设置按钮 → `On Click` → `PatternGallery.BackToRoaming()` 或 `ReplayRhythm()`。

> 3D 物体（绣球/纹样）走 **XR Simple Interactable 的事件**；
> UI 按钮（箭头/设置）走 **Button 的 On Click**。两种都能调我脚本里的公开方法。

---

## 4. 各物体接线对照表

| 物体 | 类型 | 加什么 | 事件 → 方法 |
| --- | --- | --- | --- |
| 绣球「进入游戏」 | 3D | Collider + XR Simple Interactable | Hover→SetHover(勾/不勾)；Select→`OnConfirm` |
| 关卡凤凰图标 | 3D | Collider + XR Simple Interactable | Hover→`SetHover`；Select→`LevelIcon.OnSelected` |
| 场景纹样 | 3D | Collider + XR Simple Interactable | Hover→`PatternTrigger.SetHover`；Select→`OnClicked` |
| 打击圆环 | 3D/UI | Collider（命中写 lastHitRadius） | 靠 ControllerInput 判定（见下） |
| 图鉴左右箭头 | UI | Button + Tracked Device Graphic Raycaster | OnClick→`Prev` / `Next` |
| 设置按钮 | UI | Button | OnClick→`BackToRoaming` / `ReplayRhythm` |

---

## 5. 打击关卡才用的 ControllerInput（单击/双击/长按 + 摇杆）

这类不走 Hover/Select，靠手柄输入动作：

1. 在**手柄物体**上挂 **`ControllerInput`**。
2. 它有三个 `InputActionReference` 字段，点右边小圆点选 XRI 默认动作集
   **`XRI Default Input Actions`** 里的：
   - `Trigger` → 拖给 `trigger`
   - `Grip`（侧键）→ 拖给 `sideButton`
   - `Thumbstick`（摇杆）→ 拖给 `thumbstick`
3. 单击/双击/长按的**时间判断脚本已经算好了**，你只管把这三个动作接上。
4. `RhythmConductor` 的 `input` 字段拖入这个 ControllerInput；
   `LevelSelectController`、`RoamingLocomotion` 的 `input` 字段同样拖入。

---

## 一句话流程

**3D 物体**：加 Collider + XR Simple Interactable → 在它的 Interactable Events 里
把 Hover/Select 连到脚本方法。
**UI 按钮**：加 Button → On Click 连到脚本方法。
**打击/摇杆**：挂 ControllerInput，把三个输入动作接上。
